# Quantiify — trade-fair microsite

Static one-page site promoting Quantiify (AI takeoff) at events, built by Conneqted Agents.
CAD look: drafting rulers, dimension lines, model-space viewport with a live AI takeoff demo, AutoCAD-style status bar and crosshair, title-block footer.

Palette follows optiify.ai (navy `#0B1220`, blue `#2664F5` / `#1A6BD6`, sky `#8FC2FA`, paper `#F4F8FD`, Manrope + JetBrains Mono) with Quantiify blue `#0072CE`.

No build step: open `index.html` or serve the folder.
